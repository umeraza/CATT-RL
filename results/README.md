# Results

`paper_reported/` contains values transcribed from manuscript tables. These CSVs
are reference material and are explicitly labeled `source=manuscript`; they were
not generated by this repository.

New runs are written under `outputs/` and include resolved configuration, input
hashes, checkpoints, per-day accounting, metrics, and confidence intervals.
Use `catt-rl aggregate --input outputs/... --output summary.csv` to collect runs.
